# AI社員だけの課（ai_department）への依頼対応

`ai_department/PLAN.md` で定義された「AI社員だけの課」のオペレーターとして依頼を処理する手順。課長（`ai-dept-lead`）と4名の専門AI社員（`ai-dept-docs` / `ai-dept-data` / `ai-dept-itsupport` / `ai-dept-helpdesk`）はClaude Codeのサブエージェントであり、互いに直接・再帰的には呼び出し合わない（`PLAN.md` §3）。すべて人間の操作するこのセッション経由で呼び出す。

## 0. 最初に必ず行う機密性・対象外業務チェック（最重要）

依頼内容を見たら、サブエージェントを呼ぶ前に自分で一次チェックする。

- 実在の個人名・個人メールアドレス・社外秘マーキング（「社外秘」「Only」等）・未公表の財務/人事/契約情報が含まれていないか
- 人事評価・契約締結・予算承認など法的最終決定、本番システムへの直接適用、緊急度が高くリスクに直結する業務（`PLAN.md` §2.1）に該当しないか

該当する、または疑いがある場合は **ここで処理を止める**。`ai-dept-lead` を含むどのサブエージェントにも機密情報そのものを渡さない。`AskUserQuestion` でエスカレーション（停止／匿名化して進める／ユーザーの明示的承認のもと続行）の方針を確認する。対象が上場企業の公開決算情報など明確に公開情報の場合は、この時点で進めてよい。

## 1. `ai-dept-lead` に振り分け判断を依頼する

直接専門AI社員を呼ばず、必ず最初に `ai-dept-lead` に依頼内容を渡し、以下を判断させる。
- どの分野（資料作成/データ分析/IT軽微支援/問い合わせ対応）に該当するか、複数分野なら分担・順序
- 機密情報・対象外業務への該当性（§0の自分の判断と合わせて二重チェックになる）
- どの専門AI社員に何を依頼すべきか

`ai-dept-lead` はコンテキストを持たない新規エージェントなので、依頼内容・確認してほしい観点を省略せずプロンプトに書く。

## 2. 専門AI社員へ順次（必要なら並列）委任する

- データ分析＋資料作成のように複数分野にまたがる場合は、依存関係がある限り**順次**実行する（例：`ai-dept-data` の集計結果 →`ai-dept-docs` の資料ドラフト化）。独立した作業のみ並列化する。
- 各専門AI社員は新規エージェントであり、かつ `Read`/`Write`（＋`ai-dept-data`と`ai-dept-itsupport`は`Bash`）しか持たず、**Web検索・外部データ取得手段を持たない**。前段の成果物やデータは必ずファイルとして渡し、プロンプトでそのファイルパスを明示する。
- 各専門AI社員への依頼には、守るべき前提（数値を創作しない、不明点は「不明」と明示する、信頼度の異なるデータは混同しない等）を明示的に書く。

## 3. 外部の公開データが必要な場合（専門AI社員に取得手段がないため、自分＝オペレーターが行う）

- `WebFetch` にはURL推測を避ける制約があるため、まず対象組織の公式サイト／IRページのトップから辿る。JSで動的生成されるページはリンク一覧が取得できないことが多いので、`irbank.net` のような第三者集計サイトや、該当企業ドメイン直下のPDF直リンク（例：`/content/dam/.../pdf/xx_2q.pdf` のようなパターン）を試す。
- PDFが `WebFetch` で正しく解析できない場合、ツール結果に記載されるローカル保存パス（`saved to /home/.../tool-results/webfetch-*.pdf`）を `Read` で直接読む。
- 第三者集計サイト経由のデータは、小さな要約モデルが月範囲や期間を取り違える・足し算が合わない等の誤りを出すことがあるため、「生の表の値をそのまま一字一句引用して」と明示的に指示して再取得し、数値の整合性（例：Q1+Q2単体 ≒ 累計）を自分で検算する。
- 取得したデータは `ai_department/_intake/` 配下にMarkdownでまとめ、**出典・取得方法・一次資料で未確認である旨**を明記してからサブエージェントに渡す。一次資料（決算短信原本等）で確認済みのデータと、未照合のデータを同じ確度で扱わない。

## 4. 成果物の整合性確認とレビューへの引き継ぎ

- 各専門AI社員の成果物（特に資料ドラフト）は、課長役として数値と記述の整合性、「事実」と「未確認事項」の区別、データ確度の明示が保たれているか確認する。
- 最終成果物には「AI社員によるドラフトであり、最終確認は人間が行う」旨が明記されていることを確認する（`PLAN.md` §9）。
- 一次資料未照合のデータがある場合は、人間のレビュー担当が経営会議等の前に照合すべき項目として明示的にリストアップする。
